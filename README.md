# 明日練習室 · 英文考前練習

依使用者提供照片中的紅色勾選範圍製作，涵蓋 Unit 1 *The Island Made of the Sea* 與 Unit 2 *Beyond Blood and Stains*。

- 23 個核心單字：記憶卡、發音、辨義與拼字。
- 共 83 題：原題保留來源頁碼；自編單字與海鮮閱讀題明確標示延伸題。
- 片語、文法、翻譯、句子重組、閱讀理解與中文解析。
- 25 分鐘／20 題模擬考：隨機題目及選項，交卷後顯示答案。
- 錯題本、答對率及單字熟悉度使用目前瀏覽器的 localStorage 保存。
- 響應式版面；無後端、無登入、無 API 金鑰。

## 使用

網站入口：`index.html`。可直接用瀏覽器開啟本機檔案，也可使用任意靜態網站伺服器。字型載入失敗時自動使用系統字型；語音朗讀依瀏覽器與裝置支援。

GitHub Pages：Settings → Pages → Deploy from a branch → main → /(root) → Save。

## 範圍與限制

勾選詞的衍生字未另外擴大收錄。勾在題型標題的區段收錄可見題目；只勾單題的區段僅收勾選題。

習作 Unit 1 p.2 的克漏字未拍完整，暫不出題。海鮮閱讀原題 2 選項 C、D 與原題 3 未提供，另附標示清楚的表格延伸題。犯罪現場閱讀原題 2 僅有 A–C 可見，保留這三個選項；未提供的第 3 題未補造。未勾選的 Unit 2 克漏字不納入。

句子題使用參考字序比對，忽略大小寫、空白和常用標點；不同但合理的英文表達可對照解析自行確認。填空每格需填完整單字或片語。查看答案及結束時未作答的題目記為需複習。

模擬考尚未交卷的狀態保留在當前頁面的記憶體中；重新整理會結束尚未交卷的本次測驗。已完成的進度保留在瀏覽器。清除瀏覽資料或更換裝置後，進度不會同步。
